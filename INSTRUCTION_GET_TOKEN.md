# Пошаговая инструкция: как сохранить свои файлы с Яндекс.Диска на компьютер

Для тех, кто делает такое впервые. Один шаг — одно действие. Настройка займёт 10–15 минут, дальше программа качает сама.

[![Telegram](https://img.shields.io/badge/Telegram-Канал_проекта-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white)](https://t.me/davronsv)
[![YouTube](https://img.shields.io/badge/YouTube-Видеоразбор-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://www.youtube.com/watch?v=XAiJxqHkEUA)

> [!NOTE]
> Пароль от Яндекса программе не нужен. Вы дадите ей «ключи», которые Яндекс выдаёт сам: **токен** для обычных файлов и, если нужно, **cookies** для фото с телефона. Всё хранится только на вашем компьютере.

## Что понадобится

- Компьютер с Windows 10 или 11, macOS или Linux, и интернет.
- Аккаунт Яндекса, с которого нужно сохранить файлы. В браузере вы должны быть в него вошли.
- Свободное место на диске: не меньше, чем занимают ваши файлы на Яндекс.Диске. Точную цифру программа покажет на шаге 4.
- Ставить Python или что-то ещё вручную **не нужно**: всё нужное программа скачает сама.

## Шаг 1. Скачайте программу

1. Нажмите ссылку: **[скачать программу (ZIP-архив)](https://github.com/PXSYS13/yadisk_backup/archive/refs/heads/main.zip)**.
2. Браузер сохранит файл **yadisk_backup-main.zip** в папку «Загрузки».

Это архив, внутри — папка с программой. В систему ничего не устанавливается.

---

## Шаг 2. Распакуйте архив

**Windows:**

1. Откройте папку «Загрузки».
2. Щёлкните правой кнопкой мыши по файлу **yadisk_backup-main.zip** и выберите **«Извлечь всё…»**, затем **«Извлечь»**.
3. Откроется новая папка **yadisk_backup-main**. Дальше работайте с ней.

> [!WARNING]
> Не запускайте программу прямо из ZIP-архива: Windows разрешает открыть архив как папку, но тогда программа не сможет сохранить настройки. Сначала «Извлечь всё».

**macOS:** Safari обычно распаковывает архив сам, и в «Загрузках» появляется папка **yadisk_backup-main**. Если там лежит только ZIP-файл, дважды кликните по нему.

**Linux:** щёлкните правой кнопкой по архиву и выберите «Извлечь сюда».

Папку можно переложить куда удобно, например на Рабочий стол. Файлы внутри не переименовывайте.

---

## Шаг 3. Запустите программу

### На Windows

1. Откройте папку **yadisk_backup-main**.
2. Дважды кликните по файлу **webui.bat**. Если окончания файлов у вас скрыты, файл называется просто **webui**, тип — «Пакетный файл Windows».
3. Если появилось синее окно **«Windows защитил ваш компьютер»**, нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Если окно **«Предупреждение системы безопасности»**, нажмите **«Запустить»**. Программа бесплатная, с открытым кодом; Windows просто не знает её автора.
4. Откроется чёрное окно. В первый раз в нём побегут строчки на английском: программа скачивает всё нужное. Это занимает 1–2 минуты.
5. Потом сам откроется браузер со страницей программы.

### На macOS

1. Откройте папку **yadisk_backup-main** в Finder.
2. Дважды кликните по файлу **webui.command**. Откроется окно Терминала, программа сама всё установит (1–2 минуты в первый раз) и откроет браузер.
3. Если macOS пишет, что не может открыть файл, потому что не удалось проверить разработчика: откройте **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз и нажмите **«Всё равно открыть»** рядом с `webui.command`. На старых версиях macOS вместо этого щёлкните по файлу правой кнопкой (или с зажатой <kbd>Control</kbd>), выберите **«Открыть»** и ещё раз **«Открыть»**.
4. Если двойной клик так и не сработал, есть запасной способ:
   - откройте Терминал: нажмите <kbd>Cmd</kbd> + <kbd>Пробел</kbd>, наберите **Терминал**, нажмите <kbd>Enter</kbd> (или Finder → Программы → Утилиты → Терминал);
   - напечатайте `bash` и **пробел**; Enter пока не нажимайте;
   - перетащите мышкой файл **webui.sh** из Finder в окно Терминала, путь к нему подставится сам;
   - нажмите <kbd>Enter</kbd>.

### На Linux

1. Откройте папку **yadisk_backup-main** в файловом менеджере.
2. Щёлкните правой кнопкой по пустому месту в папке и выберите **«Открыть в терминале»**.
3. Напечатайте `bash webui.sh` и нажмите <kbd>Enter</kbd>.

Если пункта «Открыть в терминале» нет: откройте Терминал (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>), напечатайте `bash` и пробел, перетащите в окно файл **webui.sh** и нажмите <kbd>Enter</kbd>.

### Что важно знать про чёрное окно

- Это окно и есть программа. **Пока оно открыто, программа работает.** Закрыли окно — программа остановилась.
- Страница в браузере с адресом **localhost:8000** — это пульт управления программой на вашем компьютере. В интернет она не выкладывается, другие люди её не видят.
- Если браузер не открылся сам, откройте любой браузер и наберите в адресной строке адрес из строки «Адрес» в чёрном окне — обычно **localhost:8000**. Если этот адрес занят другой программой (в Linux так бывает со службой печати), программа возьмёт следующий — **localhost:8001** — и напишет об этом в окне.
- В следующий раз запускайте программу так же: двойной клик по тому же файлу. Повторная установка уже не нужна, старт займёт секунды.

## Шаг 4. Получите токен

При первом запуске на «Главной» нажмите **«Начать настройку»** — откроется **«Настройка за 3 шага»**. Шаги 4–6 этой инструкции повторяют её. Вернуться к настройке можно в любой момент: вкладка **«Настройки»**, блок «Доступ».

![Настройка за 3 шага: ключ доступа к Диску, папка для файлов, безлимит](docs/images/setup.webp)

**Токен** — это ключ, по которому Яндекс разрешает программе скачивать ваши обычные файлы и папки. Он действует около года и хранится только у вас.

1. В браузере откройте [disk.yandex.ru](https://disk.yandex.ru) и посмотрите в правый верхний угол: вы должны быть в **нужном аккаунте**.
2. Откройте страницу Яндекса **[yandex.ru/dev/disk/poligon](https://yandex.ru/dev/disk/poligon/)**. Не пугайтесь слова «dev»: это официальная страница Яндекса для получения ключа.
3. Справа вверху нажмите **«Получить OAuth-токен»**.
4. Яндекс спросит, разрешить ли доступ к Диску. Нажмите **«Разрешить»**.
5. Появится длинная строка, она начинается на `y0_`. Это и есть токен. Нажмите **«Скопировать»** рядом с ней.
6. Вернитесь на страницу программы. Щёлкните в поле «Ключ доступа (токен)» и вставьте: <kbd>Ctrl</kbd> + <kbd>V</kbd> на Windows и Linux, <kbd>Cmd</kbd> + <kbd>V</kbd> на Mac.
7. Нажмите **«Проверить и сохранить»**. Программа покажет ваш логин, сколько занято на Диске и сколько фото в безлимите, и сама перейдёт к следующему шагу.

> [!WARNING]
> Не пересылайте токен другим людям: с ним можно скачать ваши файлы. Если отправили по ошибке, удалите его в программе («Настройки» → «Удалить ключ») и получите новый.

## Шаг 5. Выберите папку для файлов

1. Программа предложит папку. **Если не знаете, что выбрать, оставьте как есть** и нажмите **«Сохранить папку»**: файлы лягут в папку `downloads` внутри папки программы.
2. Хотите сохранить на другой диск, например внешний или D:? Создайте там папку и вставьте путь к ней в поле:
   - **Windows:** откройте папку в Проводнике, щёлкните по адресной строке вверху окна, скопируйте <kbd>Ctrl</kbd> + <kbd>C</kbd> и вставьте в поле. Пример: `D:\YandexBackup`.
   - **macOS:** выделите папку в Finder и нажмите <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>C</kbd>, путь скопируется. Пример: `/Users/ivan/YandexBackup`.
3. Нажмите **«Сохранить папку»**. Программа покажет, сколько там свободного места. Нужно не меньше, чем занимают ваши файлы на Яндекс.Диске.

Нельзя выбрать корень диска (`C:\`), системные папки и папку пользователя целиком. Программа такой путь не примет и объяснит почему.

## Шаг 6. Добавьте cookies для фото с телефона

**Этот шаг нужен, только если** телефон загружал фото и видео в Яндекс в «безлимит» (раздел «Фото» на Диске). Посмотрите, что показала программа на шаге 4: если в безлимите 0, нажмите **«Пропустить — качать только Диск»**.

**Cookies** — это данные вашего входа в Яндекс из браузера. Без них Яндекс не отдаёт безлимитные фото.

1. Установите бесплатное расширение **Cookie-Editor**: [для Chrome, Яндекс.Браузера, Edge и Opera](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm) или [для Firefox](https://addons.mozilla.org/ru/firefox/addon/cookie-editor/). Нажмите «Установить» или «Добавить в браузер».
2. Откройте [disk.yandex.ru/client/photo](https://disk.yandex.ru/client/photo). На странице должны быть видны ваши фото.
3. Нажмите значок расширения 🍪 справа вверху браузера. Если его не видно, нажмите значок «пазл» 🧩: там список всех расширений.
4. Внизу окошка расширения нажмите **Export**, затем **Export as JSON**. Данные скопируются; на экране при этом ничего не появится, так и должно быть.
5. Вернитесь в программу, щёлкните в большое поле «Данные входа» и вставьте: <kbd>Ctrl</kbd> + <kbd>V</kbd> или <kbd>Cmd</kbd> + <kbd>V</kbd> на Mac.
6. Нажмите **«Сохранить доступ»**. Программа сама проверит данные и напишет «Сохранено».

Если программа пишет **«Не хватает кук»**, значит, данные скопированы не на странице Яндекс.Диска или вы не вошли в аккаунт. Повторите пункты 2–6.

Cookies живут от нескольких дней до нескольких недель. Если программа позже напишет «Нужно обновить доступ к Безлимиту», нажмите в этом сообщении **«Обновить доступ»** и повторите этот шаг.

> [!IMPORTANT]
> С 11 октября 2026 года Яндекс отключил массовое скачивание (ZIP-архивы). Программа теперь забирает безлимит по одному файлу, как кнопка «Скачать» в веб-версии, — для этого и нужны cookies. Часть файлов лежит на серверах Яндекса, которые пока не отвечают: программа их откладывает и повторяет позже, остальное качает.

## Шаг 7. Запустите скачивание

На «Главной» нажмите большую кнопку **«Сохранить мои файлы»**. Программа сама получит список файлов и начнёт качать обычный Диск и безлимит одновременно.

Хотите не всё, а, например, только фото и видео? Вкладка **«Настройки»** → блок «Что скачивать»: снимите лишние галочки и нажмите «Сохранить». По умолчанию программа качает всё. Галочки только выбирают, что скачивать: файлы всё равно лягут в те же папки, что на Диске.

![Главный экран во время скачивания](docs/images/home-light.webp)

Что вы увидите:

- Вверху — что происходит сейчас, простыми словами, и одна главная кнопка. Пока программа работает, рядом мигает пульс и написано «Программа работает · последнее действие … назад» — значит, скачивание идёт, даже если число скачанных растёт медленно.
- Кольцо и четыре плитки: сколько уже **скачано**, сколько **ждут Яндекса**, сколько **в очереди** и сколько файлов программа проверила за последние минуты.
- Ниже — две карточки: «Обычный Диск» и «Безлимит». У каждой — этапы «Доступ → Список файлов → Скачивание → Готово» и строка «что делаю сейчас». Зелёная полоска — уже скачано, жёлтая — **ждёт Яндекса**: эти файлы лежат на серверах Яндекса, которые сейчас не отвечают. Программа повторяет их сама каждые 30 минут, а кнопка **«Попробовать сейчас»** — не ждать.
- Ещё ниже — «Что происходит» (главные события по времени) и «Последние скачанные» (файлы, которые уже лежат у вас в папке).
- Для фото, чей оригинал пока недоступен, программа сохраняет уменьшенную копию в папку «_превью» — на всякий случай. Оригинал докачается сам в полном качестве, и тогда превью удалится.
- Если программе нужно ваше действие (например, обновить ключ или освободить место), сверху появится сообщение с кнопкой.

Большой Диск качается часами. Пока идёт скачивание, программа не даёт компьютеру уснуть. Но если закрыть крышку ноутбука, он всё равно уснёт — оставьте её открытой.

## Где мои файлы и что дальше

- Файлы лежат в папке из шага 5. Обычный диск — с теми же папками, что на Яндекс.Диске. Фото из безлимита — в подпапке `_unlim`.
- **Открыть папку:** на «Главной» в блоке «Где мои файлы» кнопка **«Открыть папку»**.
- **Остановить:** кнопка **«Остановить»** на «Главной» или просто закройте чёрное окно.
- **Продолжить позже:** снова запустите программу (шаг 3) и нажмите **«Сохранить мои файлы»** или **«Продолжить»**. Уже скачанные файлы второй раз не качаются, а собранный список файлов программа помнит — весь Диск заново не сканирует.
- **Добавили файлы на Диск:** на «Главной» в карточке Диска нажмите **«Обновить список»**. Сама программа обновляет список раз в 6 часов.
- **Не скачалась часть файлов:** когда скачивание закончится, на «Главной» будет кнопка **«Повторить для N файлов»**. Почему именно не скачались — «Подробнее» в карточке Диска или Безлимита.
- **Разложить файлы по типам** (по желанию): вкладка «Сортировка» соберёт файлы из всех папок в общие папки «Фото», «Видео», «Документы» и другие, фото и видео — по годам и месяцам. Папки, как на Яндекс.Диске, при этом исчезнут, опустевшие папки программа удалит; сами файлы не удаляются. Сначала нажмите **«Посмотреть, что получится»** — там видно, сколько папок исчезнет, — потом **«Разложить файлы»**. Не нужно — просто не нажимайте: файлы так и останутся в папках, как на Диске.

## Скачать папку по публичной ссылке

Прислали ссылку на папку Яндекс.Диска, например `https://disk.yandex.ru/d/…`? Её можно скачать без токена и без cookies — даже сейчас, когда кнопка «Скачать всё» на сайте Яндекса не работает.

1. Запустите программу (шаг 3).
2. Откройте вкладку **«По ссылке»** в меню слева.
3. Вставьте ссылку в поле и нажмите **«Скачать»**.

![Раздел «По ссылке»](docs/images/links.webp)

- Подходят ссылки на папку, на подпапку, на один файл и на публичный альбом (`disk.yandex.ru/a/…`), в том числе короткие `yadi.sk/d/…` и `yadi.sk/a/…`. Ссылки с паролем пока не поддерживаются.
- Из альбома скачиваются оригиналы по одному. К именам добавляется ID фото: одинаковые имена не перезаписывают друг друга, а повторный запуск продолжает скачивание. Альбомы используют веб-интерфейс Яндекса; если он изменится, программе может понадобиться обновление.
- Файлы лягут в папку скачивания, в подпапку `_ссылки` → `<имя папки>`, с теми же подпапками, что по ссылке.
- Если ссылку скачивали слишком часто, Яндекс закрывает её до конца суток. Программа поставит её на паузу и продолжит сама после полуночи по Москве.
- **«Проверить новые файлы»** докачает то, что владелец добавил в папку позже. **«Убрать из списка»** не удаляет уже скачанное.

## Если что-то пошло не так

| Что вы видите | Что это значит | Что делать |
|---|---|---|
| Чёрное окно открылось и сразу закрылось | Не скачались нужные компоненты | Проверьте интернет и запустите снова. Не помогло — напишите в Telegram |
| «Windows защитил ваш компьютер» | Windows не знает автора программы | «Подробнее», затем «Выполнить в любом случае» |
| macOS: «не удаётся проверить разработчика» | macOS не знает автора программы | Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть» |
| Браузер не открылся | Ничего страшного | Наберите в браузере адрес из строки «Адрес» в чёрном окне, обычно **localhost:8000** |
| На **localhost:8000** открылась страница принтера (Linux) | Этот адрес занят службой печати | Программа сама взяла следующий адрес — посмотрите строку «Адрес» в чёрном окне, обычно **localhost:8001** |
| «Программа не отвечает — окно программы закрыто?» | Чёрное окно закрыто, программа остановлена | Запустите программу снова (шаг 3) |
| «Ключ не подошёл» | Токен скопирован не целиком или устарел | Получите и вставьте токен заново (шаг 4) |
| «Не хватает кук» | Cookies скопированы не на странице Диска | Повторите шаг 6 на странице disk.yandex.ru |
| «Яндекс перестал принимать ключ доступа к Диску» | Токен устарел | В сообщении нажмите «Получить новый ключ» и повторите шаг 4 |
| «Нужно обновить доступ к Безлимиту» | Cookies устарели | В сообщении нажмите «Обновить доступ» и повторите шаг 6 |
| «Яндекс отказывает в скачивании безлимита» | Яндекс ограничил скачивание на своей стороне | Программа не сломана. Обычный диск качается, безлимит запустите позже |
| «Часть файлов лежит на серверах Яндекса, которые не отвечают» | Сервер с этими файлами в пострадавшем дата-центре | Ничего не делайте: остальные файлы качаются, отложенные программа повторит сама. Не удаляйте их с Диска |
| Ошибки 500, 502, 503, 504 или 429 | Серверы Яндекса перегружены | Программа сама ждёт и повторяет. Можно оставить её работать |
| «Проблема с вашим диском, а не с Яндексом» | Нет места или папка недоступна | Освободите место или выберите другую папку (шаг 5) |

> [!TIP]
> Серверы Яндекса меньше всего загружены ночью и рано утром. Большой архив удобно оставить качаться на ночь.

Не удаляйте с Яндекс.Диска файлы, которые не скачиваются, и не очищайте Корзину: часть файлов временно недоступна у самого Яндекса.

## Как обновить программу

1. Скачайте архив заново (шаг 1).
2. Распакуйте его туда же, где лежит старая папка **yadisk_backup-main**: в окне «Извлечь» укажите ту же родительскую папку, например «Рабочий стол», и согласитесь заменить файлы.

Токен, cookies, выбранная папка и прогресс скачивания сохранятся: их нет в архиве, поэтому они не перезапишутся.

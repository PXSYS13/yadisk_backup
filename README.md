# Yandex.Disk Backup — массовое скачивание всего диска и безлимитного фото-хранилища

> **Готовый инструмент для миграции с Яндекс.Диска.** Скачивает обычные файлы через официальный REST API и скрытый безлимит (Photoslice — фото с телефонов) через куки браузера. Папки — как на Диске; по желанию — сортировка по типам и поиск дубликатов по MD5. Веб-интерфейс. Запуск одним кликом — зависимости ставятся сами.

## Что умеет

| Возможность | Как работает |
|---|---|
| 💾 **Скачивание обычного диска** | Через официальный REST API Яндекс.Диска. Нужен OAuth-токен (получается в один клик) |
| 📸 **Скачивание безлимита** | Скрытое фото-хранилище Яндекса — через куки браузера, по одному файлу (ZIP-архивы Яндекс отключил в октябре 2026) |
| ⏳ **Режим спасения** | Диск и безлимит качаются одновременно; файлы, которые Яндекс пока не отдаёт, откладываются и повторяются сами каждые 30 минут |
| 📁 **Только нужные папки** | Весь Диск или только отмеченные папки — в дереве папок в «Настройках». Общие папки, к которым вам дали доступ, тоже скачиваются |
| 🔗 **По ссылке** | Папка или файл по публичной ссылке `disk.yandex.ru/d/…` — без ключа доступа, файл за файлом (в браузере «Скачать всё» сейчас не работает) |
| 📂 **Папки как на Диске** | `disk:/Загрузки/Project1/Words/SomeDox.docx` ляжет в `<папка скачивания>\Загрузки\Project1\Words\SomeDox.docx`; папки с файлами разных типов остаются как есть |
| 🗂 **Сортировка по типам — по желанию** | Только по кнопке во вкладке «Сортировка»: собирает файлы из всех папок в Фото/Видео/Документы/Архивы/… (фото и видео — по годам). Папки, как на Диске, при этом исчезают |
| 🧹 **Дедупликация** | При сортировке: одинаковые файлы (по MD5) уезжают в `_duplicates`, на месте остаётся один |
| 🔄 **Resume** | Прерванное скачивание возобновляется с того же места. Хранит состояние в SQLite |
| 🌐 **Веб-интерфейс** | Тёмная тема в стиле Apple, открывается на `http://localhost:8000`, без эмодзи и шума |
| ⚡ **Параллельность** | До 5 потоков для обычного диска, до 6 воркеров для безлимита |
| 🛡 **Безопасность** | CSRF-защита, валидация путей, маскировка токена, atomic-write для куки |
| 🚀 **One-click** | Двойной клик по `webui.bat` — сам установит Python-зависимости и запустит браузер |

## Октябрь 2026: что происходит и как программа с этим справляется

После атак на дата-центры Яндекс отключил скачивание архивами, а часть серверов, где лежат файлы, сейчас не отвечает — ни программе, ни веб-версии, ни официальному API. Данные при этом не удалены: такие файлы просто временно недоступны.

Программа (с версии 1.2):

- качает всё, что Яндекс отдаёт **прямо сейчас**, — и обычный Диск, и безлимит, одновременно;
- файлы с молчащих серверов **откладывает** (не считает ошибкой) и **сама повторяет** их каждые 30 минут, пока программа открыта;
- для фото, чей оригинал пока недоступен, сохраняет **превью** (уменьшенную копию до 1280 px) в папку «_превью» — чтобы что-то было у вас уже сейчас; оригинал докачается сам, когда Яндекс его отдаст, и тогда превью удалится;
- проверяет каждый скачанный файл по размеру и MD5;
- не даёт компьютеру уснуть, пока идёт скачивание (Windows и macOS);
- честно показывает, что скачано, что ждёт Яндекса и что нужно сделать вам.

Что делать вам: нажать «Скачать всё», оставить компьютер включённым и **ничего не удалять с Диска** (и не нажимать «Освободить место» в приложении Яндекса).

## Установка и запуск

> **Впервые и не программист?** Откройте [пошаговую инструкцию для новичков](https://github.com/PXSYS13/yadisk_backup/blob/main/INSTRUCTION_GET_TOKEN.md): там по шагам, что скачать, куда нажать и что делать, если что-то пошло не так.

Проект работает на [uv](https://docs.astral.sh/uv/) — он сам ставит нужный Python и все зависимости из `uv.lock`. Отдельно устанавливать Python и pip не нужно.

### Вариант 1 — Один клик (для всех)

1. Скачай проект: `git clone https://github.com/PXSYS13/yadisk_backup.git` или ZIP с GitHub (зелёная кнопка `Code → Download ZIP`) и распакуй.
2. Запусти:
   **Windows:** двойной клик по **`webui.bat`**  
   **macOS:** двойной клик по **`webui.command`**  
   **Linux:** правой кнопкой в папке → «Открыть в терминале» → `bash webui.sh`  
   Подробно, с тем, что делать, если macOS не даёт открыть файл: [инструкция, часть 0](https://github.com/PXSYS13/yadisk_backup/blob/main/INSTRUCTION_GET_TOKEN.md#-часть-0-где-скачать-программу-и-как-её-запустить)

При первом запуске лаунчер сам установит uv (официальный инсталлер, один раз), uv скачает Python и зависимости (1–2 минуты), и откроется браузер на `http://localhost:8000`.

### Вариант 2 — Если uv уже стоит

```bash
git clone https://github.com/PXSYS13/yadisk_backup.git
cd yadisk_backup
uv run webui.py
```

## Использование

Интерфейс — пять разделов в меню слева: **Главная**, **Настройки**, **Сортировка**, **Помощь**, **Поддержать**; там же подключения (Диск, Безлимит, папка) и переключатель светлой и тёмной темы. Прежний интерфейс — ссылка внизу меню (`/?ui=old`).

На «Главной» сразу видно, что программа жива: пульс и «последнее действие … назад», этапы каждой части (доступ → список файлов → скачивание → готово), сколько файлов проверено за последние минуты, лента событий и последние скачанные файлы.

### Первый запуск: «Настройка за 3 шага»

На «Главной» нажми **«Начать настройку»**: **ключ доступа к Диску** (кнопка ведёт на Полигон Яндекса, программа проверит, чей это аккаунт и сколько там данных) → **папка** для файлов → **доступ к Безлимиту** (данные входа из браузера, можно пропустить). Всё это потом меняется во вкладке «Настройки», блок «Доступ».

### Скачивание: одна кнопка

1. На «Главной» нажми **«Сохранить мои файлы»**.
2. Программа сама соберёт список и качает Диск и безлимит одновременно. На карточках видно: скачано, в очереди, **ждут Яндекса** (их серверы сейчас молчат — повторяются сами каждые 30 минут), не скачались, есть превью.
3. Что Яндекс пока не отдаёт — кнопка **«Попробовать сейчас»**, чтобы не ждать раунда. Когда нужно действие (новый ключ, место на диске) — сверху появится сообщение с одной кнопкой.
4. Хочешь не всё — «Настройки» → «Что скачивать»: источники, типы файлов и папки Диска (по умолчанию — всё). Там же «Бережный режим» и страховочные превью.

Структура папок сохраняется: файлы из `Загрузки/Project1/Words` лягут в папку скачивания по тому же пути `Загрузки\Project1\Words`. По типам («Фото», «Документы» и т. д.) их раскладывает только вкладка «Сортировка» — и только если вы сами нажмёте «Разложить файлы». Галочки «Фото», «Документы» и другие в «Настройках» → «Что скачивать» — только выбор, что скачивать, а не папки.

### Только нужные папки и общие папки

«Настройки» → «Что скачивать» → **«Папки Диска»**:

- **«Весь Диск»** (по умолчанию) — все папки, включая общие папки в корне Диска, к которым вам дали доступ (после того как вы приняли приглашение).
- **«Только выбранные папки»** — откроется дерево папок вашего Диска: раскройте нужные ветки стрелками и отметьте папки. Отмеченная папка скачивается целиком, со всеми вложенными. Общие папки помечены значком «общая». Остальное скачиваться не будет; передумали — выберите «Весь Диск», и снятые файлы вернутся в очередь.

Список файлов программа помнит и после перезапуска, а заново собирает раз в 6 часов. Новую отмеченную папку она досканирует сразу — только её, весь Диск заново не сканируется: так найдётся и то, что скопировали на Диск уже после сбора списка. Добавили файлы на Диск и не хотите ждать — нажмите **«Обновить список»** в карточке Диска на «Главной».

Если выбранную папку на Диске переименовали или удалили, программа скажет об этом на «Главной» и попросит выбрать папки заново. Общую папку, которую перенесли внутрь другой папки, отметьте в дереве — в режиме «Весь Диск» программа ищет общие папки только в корне Диска.

### Скачать по ссылке

Прислали ссылку на чужую папку (`https://disk.yandex.ru/d/…`, `yadi.sk/d/…`, ссылку на подпапку или на один файл)? Раздел **«По ссылке»**: вставьте ссылку и нажмите **«Скачать»**. Ключ доступа не нужен.

- Файлы ложатся в папку скачивания, в подпапку `_ссылки/<имя папки>`, с теми же подпапками, что по ссылке.
- Как и с Диском: файлы с молчащих серверов Яндекса откладываются и повторяются сами каждые 30 минут, у отложенных фото сохраняется превью, размер и MD5 проверяются.
- Если ссылку скачивали слишком часто, Яндекс закрывает её до конца суток — программа поставит её на паузу и продолжит после полуночи по Москве.
- «Проверить новые файлы» докачает то, что владелец добавил в папку позже. «Убрать из списка» не удаляет уже скачанное.
- Ссылки с паролем и альбомы пока не поддерживаются. Скачивание по ссылкам идёт отдельно от режима спасения и не мешает ему.

### Безлимит (фото с телефона)

Яндекс прячет фото с мобильных приложений в скрытом хранилище. Через официальный доступ оно не отдаётся, но можно достать по данным входа из браузера:

1. Установи расширение [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm)
2. Зайди на [disk.yandex.ru](https://disk.yandex.ru/client/disk), залогинься
3. Кликни иконку Cookie-Editor → **Export → Export as JSON**
4. В программе: «Настройки» → «Доступ к Безлимиту» → вставь JSON → **«Сохранить доступ»**

### Сортировка по типам (по желанию)

Обычно она не нужна: файлы уже лежат в тех же папках, что на Яндекс.Диске. Сортировка — для тех, кто хочет собрать всё в общие папки по типам (вкладка «Сортировка»):

1. Папка уже подставлена — это папка скачивания
2. **«Посмотреть, что получится»** — сколько чего, сколько дубликатов, сколько папок исчезнет и пара примеров, куда переедут файлы
3. **«Разложить файлы»** — после подтверждения переносит файлы в структуру:
   ```
   Папка/
   ├── Фото/2024/2024-08/...
   ├── Видео/2023/2023-07/...
   ├── Документы/
   ├── Архивы/
   ├── Программы/
   ├── Аудио/
   ├── Прочее/
   └── _duplicates/  ← одинаковые файлы (можешь потом удалить)
   ```

> [!WARNING]
> Папки, как на Диске, при этом исчезают: `Загрузки\Project1\Words\SomeDox.docx` переедет в `Документы\SomeDox.docx`, а картинки из той же папки — в `Фото\…`. Опустевшие папки удаляются. Сами файлы не удаляются, но вернуть прежнее расположение автоматически нельзя. Папки `_превью` и `_ссылки` сортировка не трогает.

## CLI (если UI не нужен)

```bash
# Обычный диск
python main.py check                    # проверить токен
python main.py scan                     # построить карту диска
python main.py scan --root /Фото --root "/Работа/2024"   # только эти папки
python main.py download --workers 4     # скачать всё
python main.py retry-failed             # повторить упавшие
python main.py verify                   # проверить MD5
python main.py stats                    # статистика

# Безлимит (нужен cookies.json)
python unlim_download.py --collect      # собрать список
python unlim_download.py --status       # статус очереди
python unlim_worker.py --id 1           # запустить воркер
python unlim_worker.py --id 2           # ещё один параллельно
# ...
python unlim_download.py --retry-failed # вернуть упавшие в очередь

# По публичной ссылке (ключ не нужен)
python public_download.py --add https://disk.yandex.ru/d/XXXX   # добавить ссылку
python public_download.py --wait        # скачать, отложенное повторять раундами
python public_download.py --status      # что в списке

# Сортировка по типам (папки, как на Диске, исчезнут)
python organize.py --input "D:/Backup"                  # отчёт: что куда переедет, сколько папок исчезнет
python organize.py --input "D:/Backup" --action move    # переместить
```

## Часто задаваемые вопросы

### Запустил `webui.bat`, а он говорит «Could not install uv automatically»

Инсталлер uv не смог скачаться (фаервол, прокси, нет PowerShell). Установи uv вручную по инструкции [docs.astral.sh/uv/getting-started/installation](https://docs.astral.sh/uv/getting-started/installation/), закрой все cmd-окна и запусти `webui.bat` снова.

### Первый запуск долго «думает»

uv скачивает Python и зависимости — 1–2 минуты на обычном интернете, дальше запуск мгновенный. Если висит дольше 10 минут — проверь интернет и повтори: `uv run webui.py` в папке проекта покажет, на чём застряло.

### Установка зависимостей упала

Скорее всего uv не имеет доступа в интернет (фаервол / прокси). Попробуй вручную в папке проекта:
```bash
uv sync
```
Если ошибка повторится — скриншот в issue на GitHub.

### Сервер запустился но браузер не открылся

Открой вручную: http://localhost:8000

### Что-то не работает — как прислать логи

Вкладка **«Помощь»** → кнопка **«Скачать отчёт для поддержки»**. В архиве: логи сервера (`webui.log`), каждой задачи (`tasks/*.log`), воркеров и монитора плюс `support-info.json` с версией, ОС, состоянием очередей и диагностикой. Токена и кук в архиве нет. Там же, в блоке «Журналы программы», можно посмотреть хвост любого лога.

### Часть файлов «ждёт Яндекса» — что это?

Каждый файл хранится на конкретном сервере Яндекса. Сейчас часть таких серверов молчит. Программа замечает это за 10 секунд, откладывает файлы этого сервера (попытки не сжигаются) и качает остальные. Каждые 30 минут она пробует отложенные снова — как только сервер оживёт, файлы скачаются сами. Не удаляйте эти файлы с Диска.

### Что за папка «_превью»?

Пока оригинал фото недоступен, программа сохраняет его превью — уменьшенную копию до 1280 пикселей. Это страховка на случай, если оригинал так и не вернётся. Когда оригинал скачается, он ляжет на своё место в полном качестве, а превью программа удалит сама; превью, оставшиеся от прошлых версий, она уберёт при следующем скачивании. Сортировка эту папку не трогает. Отключить превью: «Настройки» → «Дополнительно» → «Страховочные превью фото».

Идея страховочных превью — из форка [woohung](https://github.com/woohung/yadisk_backup), спасибо!

### Файлы лягут в папки, как на Диске, или в «Документы» и «Фото»?

Как на Диске: `disk:/Загрузки/Project1/Words/SomeDox.docx` ляжет в `<папка скачивания>\Загрузки\Project1\Words\SomeDox.docx`, со всеми подпапками, а папка, где вперемешку документы и картинки, останется как есть. Галочки «Фото», «Документы» и другие в «Настройках» только выбирают, что скачивать. Собрать файлы в общие папки по типам может только вкладка «Сортировка» — и только по вашей кнопке; папки, как на Диске, при этом исчезнут.

Знаки, которые Windows не разрешает в именах (`: ? * " < > |`), на компьютере заменяются на `_`, а точка или пробел в конце имени убираются. Короткий хвост вида `_a1b2c3` появляется, только если пришлось исправить имя самого файла или два файла получили бы одно имя: с версии 2.3.1 из-за знаков в имени папки имена файлов внутри не меняются. Файлы, скачанные раньше, сохраняют прежние имена.

### Ошибки 500, 502, 503, 504 (Bad Gateway / Service Unavailable) и тайм-ауты серверов

> **Важно: это сбои на стороне серверов и дата-центров Яндекса, а не ошибка в программе!**

- Дата-центры Яндекса перегружены или повреждены и не отдают часть файлов (например, «no more reliable hosts») или сбрасывают соединения.
- **Что делает скрипт:** программа автоматически распознаёт ошибку серверов Яндекса, выводит в лог понятное пояснение, делает паузу и безопасные повторные попытки (exponential backoff).
- **Что делать вам:** не удалять базу данных и не паниковать. Просто подождите 15–30 минут либо запустите скачивание в менее загруженное время (ночью или утром). Прогресс скачивания полностью сохранён в SQLite.
- Если сбой затянулся — проверьте статус и новости в канале [t.me/davronsv](https://t.me/davronsv).

### Яндекс блокирует на 429 (Too Many Requests)

- Яндекс временно ограничил частоту запросов к вашему аккаунту или IP.
- Скрипт автоматически включает задержку (backoff) и делает паузу.
- **Рекомендации:** включите «Бережный режим» («Настройки» → «Дополнительно») — одновременных скачиваний станет вдвое меньше.

### Скачивание прерывается

- **БД сохраняет прогресс** на каждом файле — просто запусти скачивание снова, оно продолжит ровно с того же места
- Если совсем застряло — «Настройки» → «Опасная зона» → **«Забыть список файлов»**: программа соберёт список заново, скачанные файлы останутся

### Токен перестал работать

OAuth-токен Яндекса живёт примерно год. «Настройки» → «Ключ доступа к Диску» → **«Заменить ключ»**: кнопка там же ведёт на [yandex.ru/dev/disk/poligon](https://yandex.ru/dev/disk/poligon/).

### Cookies перестали работать (для безлимита)

Сессионные куки браузера живут несколько часов / дней. Зайди в браузере на disk.yandex.ru заново, экспортируй cookies снова через Cookie-Editor и вставь: «Настройки» → «Доступ к Безлимиту» → **«Обновить доступ»**.

### Указал DOWNLOAD_DIR=C:\ и сервер виснет

Программа защищена от этого — не обходит корни дисков. Укажи конкретную подпапку, например `C:/YandexBackup`.

### Безопасно ли использовать?

- ✅ **Токен и куки** хранятся только локально на твоём диске (`.env` и `cookies.json`)
- ✅ Эти файлы в `.gitignore` — не попадут в git
- ✅ Web-UI слушает только `127.0.0.1` — недоступен из интернета
- ✅ CSRF-защита: чужой сайт не сможет дёрнуть API
- ✅ Path traversal: нельзя сортировать системные папки (`C:/Windows` и т.д.)
- ⚠️ Безлимит через куки — серая зона по ToS Яндекса. Используй **только для своих данных** перед отменой подписки

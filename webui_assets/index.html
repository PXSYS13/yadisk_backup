Cookies браузера
Опционально — для скачивания безлимитного фото-хранилища.
Что это: Яндекс прячет фото с телефона в скрытом хранилище. Через REST API оно не отдаётся — нужны куки браузера.

Как получить:
  1. Установи расширение Cookie-Editor
  2. Открой disk.yandex.ru и залогинься
  3. Кликни на иконку Cookie-Editor → Export → Export as JSON
  4. Вставь JSON ниже → «Проверить» → потом «Сохранить»
Куки сохраняются только локально, в git не попадают.
